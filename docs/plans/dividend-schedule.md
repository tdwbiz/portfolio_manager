# Plan: remove DividendSchedule (phase 1 step 6 — audit 3 batch 8, `remove-dividend-schedule`)

Source: `docs/audit/03-commands-scripts-docs.md` (batch 8 + Decisions Q2), `docs/audit/01-data-model.md` (DividendSchedule sections + counts), `docs/architecture.md` §12 phase 1 step 6.

## Goal

Delete the unused `DividendSchedule` model and everything that reads it. Audit 1 found **no write path** (no admin, form, CRUD view or management command ever existed) and audit 01-counts confirmed **0 rows** in production. Removing it drops exactly one database table. Nothing else in the data model changes.

**The migration drops the table `core_dividendschedule`** (Django default table name; no `db_table` override in the model's `Meta`). Before migrating on mercury, tdw checks:

```sql
SELECT COUNT(*) FROM core_dividendschedule;   -- expected: 0
```
